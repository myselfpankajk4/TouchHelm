Phone-to-PC system casting

Android Chrome and iPhone Safari cannot share the phone screen from this page. This guide uses your phone’s system casting, independently of TouchHelm.

  1. On the desktop, open TouchHelm Settings → Wireless Display setup. Install Windows’ optional Wireless Display feature if needed.
  2. Open Windows’ Wireless Display app (or Connect on older Windows). Keep Wi-Fi enabled.
  3. On a compatible Android phone, open Cast, Wireless display, Screen sharing or Samsung Smart View, then select this PC. Confirm any system prompt.
  4. Stop sharing from the phone’s system casting controls.

Both devices need Miracast support. Google Cast-only phones and iPhone AirPlay do not connect to Windows Wireless Display directly. This is local system casting; Tailscale does not make it remote.

Receiver compatibility: Unknown. Check desktop Settings.
